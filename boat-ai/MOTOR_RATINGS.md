# 全国24場モーター評価のAI連携受け口

本ディレクトリは「ボートとデータ」の評価データを**許可された方法で取得できた場合**に、予想AIへ入力するための検証・変換器です。

サイト規約 https://www.boatrace-data.com/policy/ は自動化された大量取得を禁止しています。したがって、このコードは同サイトへの巡回アクセスを行いません。運営者の明示的な許諾・データ提供/API提供などが得られるまで、全国24場の評価の無断自動収集を有効化しないでください。

```bash
python boat-ai/motor_rating_bridge.py --authorized-csv ratings.csv --out motor_features.json
```

入力CSVの必須列: `date,venue,race,boat,motor_number,motor_grade,motor_adjusted_power,motor_top2_rate_pct`。1レース6艇、重複禁止、評価・数値形式、モーター番号重複を検証します。`observed_at`にタイムゾーン付き取得日時を保存し、`--cutoff-iso 2026-11-14T10:45:00+09:00`を付けると締切後情報を拒否します。

**注意:** この変換だけでは、既存のLightGBMモデルの入力特徴量に自動で加わりません。再学習・校正は過去時点に保存された許諾済み評価履歴が十分に集まってから実施します。評価を足し算して的中確率が上がったと報告しないこと。

競艇場コードは別途既存の公式24場対応コードと突合します。サイト規約・利用許諾・API提供可否を確認した上で、正規のデータフィードをこの受け口に接続する設計です。
