# モーター近況を含む3連単120通りモデル・検証（2026-11-14）

既存の全国24場モーター節間特徴量を利用し、3つの着順分類器から120通りの確率分布を組み立てる新しい実験モデルを学習・検証しました。**ボートとデータからの無許可取得は行っていません。**

手元で作成した学習済みPythonモデル6本、学習・検証コード、各レースの全120通りの予測CSVは、このチャットの `競艇AI_モーター節間_3連単120通り_学習済みモデル.zip` に同梱されています。リポジトリには現時点では学習済みバイナリを配置していません。

## 10月の独立テスト（4,384レース）

| 指標 | 従来特徴量 | モーター追加 |
| --- | ---: | ---: |
| 第1候補の的中率 | 9.124% | 9.329% |
| 上位3点的中率 | 21.898% | 22.240% |
| 120通りの平均負の対数確率 | 3.99164 | 3.96447 |
| 第1候補を毎回100円購入した場合の回収率 | 86.323% | 84.756% |
| 上位3点各100円の回収率 | 80.387% | 79.186% |
| 期待回収率120%以上・1日2レースまでの1点購入 | 62点 / 2的中 / 105.323% | 62点 / 2的中 / 221.935% |

2026年5〜8月の13,202レースを学習、9月の3,966レースで確率の温度を調整、10月をテストしました。オッズは取得時刻が締切より前と確認できるものだけ使っています。

**解釈:** 的中率および確率推定の損失は改善した一方、全レース購入の回収率は悪化しました。62点中2点的中の限定条件は極めて不安定で、利益を示す証拠にはなりません。学習済みモデルを最新の全24場データに自動適用する配信処理、正式な節IDの検証、モーター交換日の一次ソース照合はまだ未完了です。

詳細な入力仕様・再実行方法はチャット配布ZIPの README を参照。既存の `boat-ai/build_motor_features_v2.py` は履歴から事前のモーター特徴量を計算するために利用できます。
