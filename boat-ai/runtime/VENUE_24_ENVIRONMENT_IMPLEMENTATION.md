# 全国24競艇場・条件対応：実装と検証結果

更新日：2026-11-17

## 取り込んだ外部根拠

- 競艇ナビ全国24場: https://kyoutei-navi.com/category/place/ （各場の概況、コース傾向、水面）
- 競艇ナビ宮島の詳細: https://kyoutei-navi.com/place/miyajima/ （潮の影響、難水面、風向きの変化の説明）
- 宮島ボートレース公式水面説明: https://www.boatrace-miyajima.com/surface.html （満潮時は追潮でイン有利、干潮時は向潮でアウト有利、潮位によるうねり）
- 艇愛ボートレースDBの24場風向定義: https://boatrace-db.jp/about/data/ （スタート→1マークへの方角と風が「吹いてくる」8方位による向かい風・追い風・横風）
- BoatraceCSV直前気象資料: https://boatracecsv.github.io/docs/data/previews.html （締切約5分前のsui/風向・風速・波高）
- 先に登録済みの `venue_context.py` : 2021～2025の24場コース別1着率と水質/難水面/潮影響

## 実装済み

1. `venue_conditions.py`：24場の進行方位と向かい風/追い風/斜め/横風の分類、各場の水面難易度・水質・潮の影響と競艇ナビの24場一覧の説明の整理。
2. `fetch_preclose_wind.py`：日付・場・レース番号・締切時刻に一致する事前風向のみをBoatraceCSV `previews/sui` から取得。異レース、古い観測、未来の観測、締切後の値は排除。取得失敗なら未取得のまま。
3. `screenshot_input.py`：スクリーンショットから文字として確認できた風向8方位/「向かい風・追い風・横風」と潮の状態・潮位を受け付ける。矢印だけで北東/南西を勝手に推測しない。風向が2ソースで食い違えば補正を適用しない。
4. `auto_predict.py`：従来28項目AIを維持したまま、場・風向・風速・潮位の観測状況、欠損、参照元、研究用別120通りを `latest_results/venue_environment_research.json` に記録。
5. `conditional_roles_3y.py`：**24場×予定進入コース6種類＝144の相互作用特徴量を、過去の正式着順から学習**。これまでの14特徴→158特徴。結果を使う日付は一日前以前だけ。
6. `score_conditional_live.py`：既存モデル/条件付きEloモデルを並行計算し、各モデルの環境条件研究版を `EXP_water_wind_incumbent` と `EXP_water_wind_conditional` として別120通り出力。通常のTOP5を研究値で上書きしない。
7. `archive_research.py`：研究版の予測時刻と120通りも保存。締切後の再計算は締切前予想に算入しない。
8. GitHub Actions：`boat-conditional-roles.yml` 学習・時系列評価、`boat-venue-conditions.yml` 24場の条件分岐検証、`boat-venue-e2e.yml` 実データを用いた全工程の再生テスト（レース終了後の再生と明記）。

## 実測モデルの公平な研究成績

2023年11月～2026年6月学習133,807レース、7～8月検証9,055レース、9～10月最終比較8,490レース。

| 同期間比較 | Elo + 過去コース履歴（従来） | 24場×コース144特徴入り条件付き2・3着 |
|---|---:|---:|
| 3連単TOP5的中率 | 32.34% | **34.04%** |
| 3連単対数損失 | 3.9456 | **3.8343** |

7～8月に事前選択した従来との混合+温度補正版はTOP5 **33.92%**、対数損失 **3.8302**。

注意：9～10月はこれ以前の別の研究でも参照済みであり、研究全体として真に未閲覧の「完全独立テスト」ではありません。また既存の本番28項目AIには当時の全展示データがないため、既存本番モデル対新モデルの同条件大型過去検証にはなっていません。

## 風・潮の「研究用」調整と残余課題

- **風向（全24場）**：スタート→第1マークの実際の進行方位ごとに8方位の風を向かい風、追い風、斜め向かい風、斜め追い風、横風へ変換。場ごとの難水面/普通/静水面で影響を弱める小さな仮説重みを別確率で試験。**この風補正係数は過去から学習したものではなく、回収率・精度の改善も証明していない**。予想本体に混ぜず比較用。十分な数の事前風向がなければ補正しない。
- **潮位（宮島の実証された定性的傾向）**：満潮/上げ潮と干潮/下げ潮で第一コース/外側コースを少し変える**仮説の研究用シナリオ**を用意。満潮・干潮の「時刻のデータ」と「ボートレース競走水面での実測潮流」は異なる。未確認なら無補正。
- **潮位（ほか23場）**：競艇ナビの潮汐影響大小は表示済み。ただし満潮/干潮によるコース別有利不利を宮島と同じ向きに当てはめる根拠はないため、数値補正はしていない。
- **過去展示ST**：既存のBOAT RACE公式K結果キャッシュは展示STを含まない。BoatraceCSVに残る `previews/stt` の収録期間・保存条件を別途検証し、リークのない再学習を行う必要あり。
- **風・潮を学習したモデルの精度向上は未検証**。入力の受け口と24場別分類・小幅な研究用影響は完了したが、風と潮の過去の十分なレース時刻データを結合して訓練した環境条件モデルは、まだできていない。

## 本番運用ルール

- 通常の既存28項目AIと新・条件付きElo AIは継続表示。
- 研究用の水面条件別予想は**別枠**で、入力がないと変化させない。研究で検証できるまで購入推奨・実賭け・既存本番モデルの自動置換はしない。
- 24場データの定義、風・潮の観測時刻、予測時刻、レース締切時刻、実際の的中順位を分離保存。実レースで前向きに比較する。
