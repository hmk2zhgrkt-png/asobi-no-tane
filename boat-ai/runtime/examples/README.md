# 競艇AI 実スクショを使った3連単モデル検証（2026-11-15）

このフォルダには、ユーザー提供スクショ（徳山5R）から転記した実際の6艇データと45通りのオッズが入っています。予測本体の `boat-ai/runtime/exploratory_screenshot_predict.py` は、本リポジトリに配置済みの学習済み LightGBM モデル3本を実際に呼び出し、**3連単120通りすべての確率**を計算して結果CSVを出力します。

## GitHub Actions
`.github/workflows/boat-ai-screenshot-replay.yml` の [Actions画面](https://github.com/hmk2zhgrkt-png/asobi-no-tane/actions/workflows/boat-ai-screenshot-replay.yml) から、過去レースの画像由来データで推論を再生できます。ワークフローはモデルZIPのSHA-256検証後、120通りの確率が合計1、人気上位45点オッズと照合、購入ゼロを検証します。

## 取得できた情報と欠損
- スクショ: 選手6名/モーター番号/展示タイム/ST/進入/風速/波高/チルト、オッズ45通り。
- 保存済み公式成績: 2023-11-01〜2026-10-31 の履歴。11/1〜11/14 は今の履歴にはありません。
- モーター交換・近況: 過去に生成された徳山のモーター世代資料による履歴。交換日・開催節について一次出典での照合は未完了。
- 今節の選手調整・節間変化: **未取得**（空欄）。当該モデルの168個の必要入力値のうち134個のみ存在。

そのため結果は **EXPLORATORY_NO_BETS**（不完全データでの参考計算）です。モデルはLightGBMの欠損値処理により予測自体は可能ですが、今の機力を正確に反映したと保証できず、推定EVで実購入/仮想購入を行うべきではありません。

画像の値はChatGPTが目視で転記しており、プログラム自体のOCR連携はありません。利用者による定期的な画像送信と、AIによるCSV転記が必要です。

**完了したもの**: ローカル推論、120通りの確率算出、45通りオッズとの照合、GitHubへコード・データ・テストワークフローの登録。

**未完了**: Actions実行結果の直接確認、11/1以降の履歴更新、今節の正規データ取得、画像からGitHubへ投入する完全自動化、正式な期待回収率120%以上を判定する本番運用。

「ボートとデータ」の無許可の大量収集は行いません。
