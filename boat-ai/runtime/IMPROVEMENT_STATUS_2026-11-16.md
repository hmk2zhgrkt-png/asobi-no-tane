# 競艇予測AI：2026-11-16 改善記録

実装、検証済み数値、未完了条件を区別するための研究記録です。出走結果・展示成績の後知恵を学習に混入させないことを最優先にします。

## 今回実装し、GitHub Actionsで検証したもの

- **条件付き2・3着モデル**：1着の候補を条件として2着を推定し、1・2着を条件として3着を推定。3連単120組を毎回正規化。説明・モデル・学習データ検証は `conditional_roles_3y.py` と `course_training_3y/conditional_roles_evaluation.json`。
- **独自Eloの統合実験**：既存28項目モデルを変更せず、独自Elo＋過去コース履歴＋条件付きモデルの研究用120通り、および既存モデルとの25%、50%、75%混合案を `score_conditional_live.py` で計算。`.github/workflows/boat-own-elo-live.yml` でレースIDを検証してから実行。
- **会期日次を補完**：公式出走表の「前日」の成績を保存済み公式K結果で照合。選手2名以上、唯一の対応日次が確定した場合だけ `meeting_day_infer.py` で日次を採用。丸亀11R（11/16）の実データでは6選手一致、2日目と判定。曖昧な場合は欠損のまま。
- **時点を明示した記録**：`archive_preclose.py`、`archive_research.py` でスクショ観測時刻・モデル計算時刻・締切時刻を区別し、後日再計算を「締切前予測」と取り違えない。1レースにつき最新の真の締切前予測1つだけを集計する。
- **展示F.01～F.04のプラス補正と検証基盤**：`exhibition_f_bonus.py` の控えめな研究用補正は実装済み。ただし公式Kファイルには過去の展示STがないため、`audit_forward_models.py` と `calibrate_forward_models.py` で今後の真の締切前サンプルから補正効果を測定し、最低400レースを満たさない限り確率再校正しない。
- **日次データ**：公式K確定結果は毎日02:00 JST更新（`boat-k-daily-cache.yml`）。11/01–15は2,040レース、12,240選手レコード、欠損日0日。昨夜以前の結果だけを予想に使用。

## 重要な残課題（未達成を完成と表現しない）

1. **既存28項目LightGBMとの8,490レース同条件比較は未完了**。公式K結果には全レースの締切前展示ST・展示タイム・天候などが記録されていません。これらをあとから結果で埋めたり、存在しない数値を仮定しません。真の予測をレース前に取得・保存したものだけで比較します。
2. **展示Fの有効性は未証明**。F.01～F.04をプラス扱いするのはユーザー指定の研究用補正で、展示Fと着順の因果関係を示す根拠はありません。最初の「本格的な」28項目モデル確率再校正と補正比較に必要なサンプルは、締切前にモデルを実行した最低400レース（前半300以上で最適化、残り100以上で独立評価）です。現在は有効サンプル0（過去の試算を締切前計算と偽りません）。
3. **今節展示履歴の欠損は残ることがあります**。公式K結果は着順と本番STを含むが、過去の展示タイムは含まないため、その項目だけは未取得のまま。確実な公式スナップショットが取れる場合のみ補完。
4. **実際の購入はなし**。全モデルとも未検証の損益・回収率は計算しない。オッズ120通りが揃わない場合、期待回収率は表示しない。

## 自動化と判定方針

- 毎レース：既存AI予想を保存し、独自Elo＋条件付きモデルを研究用に並行算出。レース一致・予測時刻を照合。
- 毎日：`boat-forward-audit.yml` で締切前に実際に計算した予測と確定結果を照合し、展示F・確率補正のデータ数を報告。
- 過去テストで改善しないモデルは **現行本番モデルへ自動置換しない**。
