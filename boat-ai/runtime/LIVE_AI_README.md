# Boat AI - 一連の実戦入力（2026-11-15）

この実装では、過去約3年の公式成績から集計した独自履歴を GitHub の `boat-ai/runtime/data/*.gz.b64` に置き、[BoatraceCSV](https://boatracecsv.github.io/) の MIT ライセンスの公開CSVから11月1日以降の出走表/確定結果/過去展示・当日の展示/気象/3連単120通りのオッズを取得します。無許可となったサイト「ボートとデータ」は使いません。

**入力**: GitHub の `boat-ai/runtime/request.json` の `date,venue,race` を更新するか、Actions → `Boat AI - real data inference and paper log` → Run workflow から指定してください。venue は01〜24（徳山18、戸田02）。GitHubからのアクセスは15日間の履歴差分取得などで時間がかかる場合があります。ユーザーがChatGPTへスクショを送った場合、ChatGPTが実際の会場・日付・レースを確認して request.json を更新することも可能です（チャットに追加された画像をGitHub Actionsが自動OCRするわけではありません）。

**出力**: Actions artifactと `boat-ai/runtime/latest_results/` に、 `features6.csv`、`predictions120.csv`（120点確率とオッズ、簡易期待値）、`paper_candidates.csv`（正式条件を満たした場合のみ最大3点）、`report.json` を出します。 `paper_ledger.csv` に仮想購入を保存します。現金の投票は絶対に実行しません。

**安全上の制約**:

- 公式の締切前かつ公開CSVの展示/オッズが全て時刻付きで揃っている場合だけ仮想購入候補を許可します。締切を過ぎたテストは `REPLAY_OR_UNVERIFIED_NO_BETS` になります。
- 予想対象レースの確定結果を予想時点に混入しないよう、履歴の差分追加は前日以前の確定結果だけを使用します。今節の着順/STは出走表の過去日スロットだけを利用します。
- モーター更新日が現在の公式データと違う場合は過去世代のモーターを無視します。初日やデータがない場合のNaNは構造的欠損で、捏造しません。
- `BoatraceCSV` の3連単オッズは締切前の「集計中」参考値であり確定オッズと異なる可能性があります。120%以上というのはモデル確率×参考オッズで、利益の保証ではありません。
- 前月末の集計スナップショットからその後の日付分のCSVを再取得するため、将来は起点スナップショット更新を高速化する必要があります。現在の基準日は2026-10-31です。
- GitHub Actionsは投稿画像自体を読みません。スクショだけでのGitHub起動は、このチャットからリクエストを更新する処理が必要です。
- ユーザーから正当な公開許可がある情報のみ使用。`BoatraceCSV` の当日データ提供タイミングはサイト側に依存し、欠損時は必ず見送り。

### 動作確認
ローカルの模擬CSV（オッズ120通りはテスト用）からモデルを呼び出し、レースキー `202611151805` の120通りの確率和が1になることと、過去レースの仮想購入を拒否することを確認済み。GitHub Actions上の完全自動実行はワークフローの成功記録が確認できたときだけ完了扱いにします。
