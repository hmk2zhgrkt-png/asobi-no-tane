# 現行モーター・節間推移の実データ検証

2026-11-14 にローカルで公式成績アーカイブと締切前データを用い、全国24場の **23,015レース / 138,090艇** の過去時点特徴量を生成した。対象期間は2026-05-03〜2026-10-31で、欠落があるため全開催レースを網羅していない。

- `build_motor_features_v2.py`: モーター交換日を基点に直近5走、前走までの相対展示タイム、同一選手・同一モーター連続出走区間（stint）の変化を計算。処理時点の結果はそのレースの特徴量に入れない。
- `evaluate_motor_features_v2.py`: 既存3年履歴特徴量と締切前情報のA/B比較。2026年5〜8月学習、9月検証、10月テスト。
- テスト結果: 2026年10月の**4,384レース**で、1着艇選択の的中率が**55.269% → 55.611%**、正解艇の負の対数尤度が**1.23470 → 1.22117**。これは別個の実験用モデルの結果であり、3連単の的中率・期待回収率や本番モデルへの組み込み完了を意味しない。

### 利用手順
```bash
pip install pandas numpy scikit-learn
python boat-ai/build_motor_features_v2.py --preclose --boat-csv モデル入力_選手別_締切前.csv --labels-csv 正解ラベル_選手別.csv --cycle-starts 24場_現行モーター交換日.csv --out motor_features.csv
python boat-ai/evaluate_motor_features_v2.py --motor motor_features.csv --baseline ３年履歴特徴量_選手別.csv --preclose モデル入力_選手別_締切前.csv --labels 正解ラベル_選手別.csv --summary comparison.json --predictions predictions.csv
```

### 注意
- モーター交換日の一覧は過去の作業で収集されたもので、24場分すべての一次ソースとの照合は済んでいない。確定した周期履歴として利用しない。
- `stint` は同じ選手・モーターが2日以内に続けて出走した区間を近似し、正式な節IDとは異なる。
- 今回のデータ収集は「ボートとデータ」を利用していない。同サイトの取得許可はないためスクレイピングしない。
- このリポジトリに学習済み3連単モデル本体および継続稼働パイプラインは存在せず、本番の3連単AIへの接続、再学習、回収率検証は未完了。
