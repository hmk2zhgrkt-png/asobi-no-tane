# 🌱 あそびのタネ

1〜6歳向けのおうち遊びを探せる、無料のスマホ対応Webアプリです。

**公開URL:** https://hmk2zhgrkt-png.github.io/asobi-no-tane/

## 機能

- 遊び110種類（年齢・所要時間・遊び方・道具・キーワード・片付け不要で絞り込み）
- 条件に合う遊びをランダム提案
- お気に入りの追加・削除・再表示（ブラウザのローカル保存）
- スマホの共有機能・リンクコピーによる遊びの共有
- 自分の端末内の利用イベント回数の記録（訪問・抽選・共有・お気に入り操作）

## アクセス解析について

**実際の訪問者数を集計する外部アクセス解析は初期状態では無効です。**
ローカル保存の回数は「サイト全体の訪問者数」ではありません。

一般公開後のアクセス数を確認するには、Cloudflare Web Analytics（無料プランあり）でサイトを追加し、発行されたトークンを `analytics-config.js` の `CLOUDFLARE_WEB_ANALYTICS_TOKEN` に設定してください。GitHub Pagesの公開URLを登録します。トークンを設定した後、Cloudflare側のダッシュボードでアクセス数を確認できます。設定する場合は、サイトのプライバシー表記も実際の解析設定に合わせて更新してください。

## 公開

GitHub Pages の `main` ブランチ `/(root)` を公開元に設定します。ビルド不要のHTML/CSS/JavaScriptです。

## 安全上の注意

小さな部品や危険な道具は避け、大人の見守りのもとで遊んでください。遊びの年齢は目安です。
